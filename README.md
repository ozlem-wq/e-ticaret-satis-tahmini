# e-ticaret-satis-tahmini
Bu proje, bir e-ticaret platformunun geçmiş satış verilerini kullanarak gelecekteki satış performansını tahmin etmeyi amaçlamaktadır. Zaman serisi analizi ve makine öğrenmesi (ML) yöntemleri karşılaştırılarak, en doğru öngörüyü sağlayan model belirlenmiş ve etkileşimli bir dashboard ile sonuçlar sunulmuştur.
